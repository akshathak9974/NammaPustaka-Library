# 📚 Namma-Pustaka Library

## 📖 Project Description

Namma-Pustaka is a Smart Library Assistant Android application developed using Kotlin and Jetpack Compose. The application helps schools and educational institutions digitize traditional library management systems by providing an easy-to-use platform for teachers and students.

The app allows teachers to manage books, register students, issue and return books, track overdue books, and monitor reading activity using a leaderboard system. Students can browse books, search by category, reserve books, scan QR codes, and submit reviews and ratings.

The project uses Room Database (RoomDB) for offline data persistence and includes QR-based borrowing functionality for a modern smart-library experience.

# ✨ Features

## 👩‍🏫 Teacher Features
- Teacher Login
- Register Students
- Add New Books
- Upload Book Cover Images
- Manage Books
- QR-Based Book Borrowing
- Issue & Return Books
- Overdue Tracking with Fine Calculation
- Reading Leaderboard

## 👨‍🎓 Student Features
- Student Login
- Browse Book Catalog
- Search Books
- Filter by Category
- View Book Details
- Reserve Books
- Review & Rating System
- View Reserved Books
- Student Reading History

## 📱 Smart Features
- QR Code Generation
- QR Code Scanning
- Persistent Local Storage using RoomDB
- Dynamic Leaderboard
- Offline Support
- Modern Material UI
